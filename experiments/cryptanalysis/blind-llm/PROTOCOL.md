# Blind LLM attack: protocol

**Date:** 2026-10-13
**Question:** can a model crack Cistergraphia given nothing but a set of SVGs?
**Result:** all 10 messages recovered exactly in about 2.5 minutes. See [REPORT.md](REPORT.md) and [ANSWERS.md](ANSWERS.md).

## Setup

- **Attacker:** a Claude agent (Claude Code general-purpose subagent, same model family as the
  session that ran the experiment), with shell and Python 3 available.
- **Ciphertexts:** the 10 game-mode SVGs in [`corpus/`](corpus/), generated by the encoder at
  commit `55698fb` (decoder + snail layout + unambiguous glyphs). The SVGs contain only
  `<line>` coordinates: no name, comment or metadata hinting at the scheme.
- **Plaintexts:** never written to disk during the experiment (passed to the encoder on stdin),
  so the attacker could not stumble on them.

## Rules given to the attacker

- Read only the folder holding the 10 SVGs; do not read, list or search `/home/user`, any git
  repository, or anything else on the filesystem; do not look for the encoder's source.
- No web access (no WebSearch, WebFetch, curl, pip...).
- Scripts allowed (Python 3 standard library), in a separate work directory.
- Any general knowledge allowed.
- Report the plaintexts, the method, the effort per step and an assessment.

The full prompt:

> You are taking part in a cryptanalysis experiment (authorized: the cipher belongs to the user
> who asked for this test). You are a ciphertext-only attacker.
>
> The folder `.../blind` contains 10 SVG files (msg01.svg … msg10.svg). Each one hides a short
> text message produced by the same unknown encoding scheme. Your goal: recover the plaintext of
> as many messages as possible.
>
> Strict rules (the experiment is invalid if you break them): Only read files inside that `blind`
> folder. Do NOT read, list, grep or search anything under /home/user, any git repository, any
> other part of the scratchpad, or anywhere else on the filesystem. Do not look for the encoder's
> source code. No web access [...]. You may write and run your own scripts [...] keep them in a
> new directory such as /tmp/claude-0/attack-work [...]. You may use any general knowledge you
> already have.
>
> Report back: 1. the recovered plaintext for each file [...] 2. your step-by-step method [...]
> 3. roughly how long or how many attempts each step took [...] 4. your assessment of how strong
> the scheme is.

## Evidence and limits

- [`agent-scripts/`](agent-scripts/) holds the 6 scripts the agent wrote, unmodified. They only
  read the SVG folder passed as an argument and their own intermediate JSON files, which supports
  its claim of isolation. Isolation was **instructed, not enforced** by a sandbox.
- The report (one false start on the K–R range, J guessed from a gap) reads like genuine
  solving, not recall.
- One model, one run, 10 messages. The secret mode was not given to the LLM: AES-256-GCM output
  has no structure to reason about, and the scripted attack shows it stops at the first step.
- Contamination: the tablet values, the spiral layout and the current glyph geometry were all
  published in this repository on the day of the experiment, so they cannot be in any model's
  training data. The agent derived them from the numbers.
